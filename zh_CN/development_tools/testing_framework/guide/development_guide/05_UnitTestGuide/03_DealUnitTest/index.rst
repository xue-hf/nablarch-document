========================
取引单元测试的实施方法
========================

取引单元测试中，将测试目标应用程序部署到应用程序服务器，
手动操作应用程序进行测试。

如果伴随同步响应消息发送处理，则使用模拟类进行。详情请参考\ :ref:`dealUnitTest_send_sync`\。

按每个测试用例执行以下步骤进行测试。

测试准备
==========

测试准备执行以下操作。

* 数据库准备（数据投入）
* 应用程序部署
* 应用程序服务器启动


测试实施
==========

按照测试用例进行测试。

.. tip::
 证据中的DB转储需要测试执行前的数据，因此\
 请在测试实施前获取。


测试结果证据的收集
==========================

获取以下证据。

* 画面硬拷贝
* DB转储(测试执行前及执行后)

.. tip::
  画面硬拷贝获取工具、DB转储获取工具等测试辅助工具目前正在研究中。
