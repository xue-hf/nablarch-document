=========================================
双重提交防止功能的测试实施方法
=========================================

Nablarch上的应用程序中双重提交防止功能在\
服务器端和客户端起作用。\
因此请求单元测试和取引单元测试的测试方法不同。

以下分别记述测试实施方法。

--------------------------------------------------------------
请求单元测试中双重提交防止功能的测试实施方法
--------------------------------------------------------------

在请求单元测试中，在服务器端实施测试。


双重提交防止功能测试专用，在测试用例的LIST_MAP中有isValidToken列。将此列设置为「false」，如果发生错误，则可以确认双重提交防止功能正在工作。\

测试数据的详细描述方法请参考「\ :ref:`request_test_testcases`\」。

---------------------------------------------------------
取引单元测试中双重提交防止功能的测试实施方法
---------------------------------------------------------

在取引单元测试中，在客户端实施测试。


步骤如下。

* 在调试模式下启动应用程序。

* 对被测请求对应的Action处理设置断点。

* 通过按键选择被测请求的按钮。

* 在断点停止处理的状态下，再次选择被测请求的按钮，确认请求未被发送。
