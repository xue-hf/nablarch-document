====================================================
请求单元测试的实施方法(文件上传)
====================================================


文件上传的测试是Web应用程序测试的一种。
因此，要实施文件上传的测试，需要以Web应用程序的\ :doc:`index`\ 为前提。

测试文件上传时，需要在HTTP请求参数中指定上传文件。\
本项说明在HTTP请求参数中指定上传文件的方法。\



上传文件的描述方法
==============================

通过在HTTP请求参数的值中记载以下描述，
可以在HTTP请求参数中指定上传文件。

.. code-block:: text

 ${attach:文件路径}

.. tip::
 文件路径是\ **从测试执行时的当前目录开始的相对路径**\ ，即，
 从项目根目录开始的相对路径。
 

二进制文件的情况
======================

图像文件等二进制文件上传时，请事先配置好文件，
指定该文件的路径。


以下示例中，使用uploadfile这个键，上传项目下test/resources/images\
目录中的picture.png。

.. code-block:: text

  <project_root>
       + test
          + resources
             + images
                + picture.png

------


``LIST_MAP=requestParams``

+---------------------------------------------------+----------------------+-----------+
| uploadfile                                        | comment              | public    |
+===================================================+======================+===========+
| ``${attach:test/resources/images/picture.png}``   | 上传。 | ``false`` |
+---------------------------------------------------+----------------------+-----------+


------

固定长度文件、CSV文件的情况
=================================

上传\ :ref:`固定长度文件<how_to_setup_fixed_length_file>`\或
:ref:`CSV文件<how_to_setup_csv_file>`\时，\
将其文件内容记载在测试数据表中。\
测试执行时，自动测试框架会根据此数据创建文件。


以下示例中，在work目录下创建member_list.csv文件，
将该文件指定为上传目标。

------

``LIST_MAP=requestParams``

+------------------------------------+-----------------------+
| uploadfile                         |  comment              |
+====================================+=======================+
| ``${attach:work/member_list.csv}`` |  注册10月度新会员 |
+------------------------------------+-----------------------+


``SETUP_FIXED=work/member_list.csv``


     
// 指令

+------------------+-------------+----------------------------+
|text-encoding     |Windows-31J  |                            |
+------------------+-------------+----------------------------+
|record-separator  |CRLF         |                            |
+------------------+-------------+----------------------------+

// 数据

+----------+-----+-----------------------+
| name     | age |        address        |
+==========+=====+=======================+
| 山田太郎 |  30 |东京都港区芝浦1-1      |
+----------+-----+-----------------------+
| 田中次郎 |  20 |大阪府门真市东田町2-2  |
+----------+-----+-----------------------+

------

.. tip::
 即使上传固定长度文件或CSV文件时，
 也可以像二进制文件一样事先准备好文件，
 但考虑到测试数据的可维护性，应该记载在测试数据表中。
