====================================================================
请求单元测试的实施方法（无响应消息接收处理）
====================================================================

--------------------
概述
--------------------
无响应消息处理用的Action类作为Nablarch的一部分提供。
因此，在请求单元测试中使用此Action类，确认以下\ `测试目标交付物`_ 。

**※ 不需要像其他测试那样进行Action类的条件覆盖、边界值测试等。**

测试目标交付物
===================
* 定义报文布局的格式定义文件
* 向数据库注册报文时使用的Form类
* 向数据库注册报文的INSERT语句

--------------------
测试类的编写方法
--------------------

测试类需要满足以下条件进行创建。

* 测试类的包名为测试目标功能的包名。
* 以<报文的请求ID>RequestTest作为测试类的类名进行创建。
* 继承\ ``nablarch.test.core.messaging.MessagingReceiveTestSupport``\ 。

例如，测试目标功能的包名为nablarch.sample.ss21AA、报文的请求ID为RM21AA100时，测试类如下所示。

  // ～中略～

各种期望值
==============

响应消息
--------------------

无响应消息接收处理中，由于不存在响应报文，因此不需要确认响应报文是否符合期望值。只需确认期望的数据库状态。

因此，不需要记述响应消息(「MESSAGE=expectedMessages」)。
