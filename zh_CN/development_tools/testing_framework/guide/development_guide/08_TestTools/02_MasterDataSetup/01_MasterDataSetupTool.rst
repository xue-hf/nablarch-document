==============================
主数据投入工具
==============================

概述
====


提供向数据库投入主数据的功能。


特点
====

* 可以使用与自动测试测试数据相同的形式描述。
* 使用Nablarch Application Framework的组件配置文件，无需另外准备配置文件。
* 可以同时执行向备份用模式 [#]_ 的数据投入。

.. [#]
  备份用模式是指自动测试框架的 :doc:`../../06_TestFWGuide/04_MasterDataRestore` 中使用的模式。需要向备份用模式投入与自动测试用模式相同的主数据，使用本工具可以同时向2个模式投入数据。

.. important::

  本工具不支持多线程功能。
  多线程功能的测试请在不使用测试框架的测试(集成测试等)中进行。

使用方法
========

前提条件
----------------

请参考 :doc:`02_ConfigMasterDataSetupTool` 的 :ref:`master_data_setup_prerequisite`

数据创建方法
----------------

将要投入的数据记载到MASTER_DATA.xlsx。记载方法与自动测试相同。
关于数据记载方法，请参考『 :ref:`how_to_write_setup_table` 』。

执行方法
----------------

从Ant视图中双击要执行的目标。


.. image:: ./_image/build_file_in_view.png
   :scale: 100

.. tip::
  关于Ant视图的设置，请参考 :ref:`how_to_setup_ant_view_in_eclipse` 。


目标详细如下表。

 +-----------------+----------------------------------------------------------------------------+
 | 目标名          | 说明                                                                       |
 +=================+============================================================================+
 |数据投入(main)   | 使用main项目的配置文件向数据库投入数据。                                   |
 |                 | 取引单元测试等，在AP服务器上运行应用程序时的                               |
 |                 | 模式中投入数据。                                                           |
 +-----------------+----------------------------------------------------------------------------+
 |数据投入(test)   | 使用test项目的配置文件向数据库投入数据。                                   |
 |                 | 向自动测试使用的模式中投入数据。                                           |
 |                 | 同时向主数据备份模式投入数据。                                             |
 +-----------------+----------------------------------------------------------------------------+
 |主数据投入       | 批量执行上述2个目标。                                                      |
 +-----------------+----------------------------------------------------------------------------+
