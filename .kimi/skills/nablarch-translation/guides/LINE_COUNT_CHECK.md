# 翻译行数偏差检查工具

## 用途

检查翻译后的文件与原文文件的行数偏差，用于校验翻译内容是否严重不足。

## 脚本位置

项目根目录: `check_line_count_diff.py`

## 使用方法

### 检查所有文件

```bash
python check_line_count_diff.py
```

### 检查指定目录

```bash
python check_line_count_diff.py application_framework/handlers
```

### 调整阈值

默认偏差阈值为 10，偏差小于 -10 视为严重不足：

```bash
# 使用阈值 5（更严格）
python check_line_count_diff.py --threshold 5

# 使用阈值 20（更宽松）
python check_line_count_diff.py --threshold 20
```

### 显示详细信息

```bash
python check_line_count_diff.py --verbose
```

## 输出格式

```
文件路径: +偏差值 (日文行数 -> 中文行数)
```

例如:
```
web/index.rst: +5 (120 -> 125)
web/architecture.rst: -15 (200 -> 185)
```

## 偏差值说明

| 偏差值 | 含义 | 建议 |
|--------|------|------|
| +N | 中文比日文多 N 行 | 可能添加了说明或格式调整，正常 |
| 0 | 行数相同 | 理想状态 |
| -1 ~ -9 | 轻微不足 | 可能是正常精简，可接受 |
| -10 ~ -20 | 中度不足 | 建议检查是否遗漏内容 |
| < -20 | 严重不足 | 必须检查，可能大量内容未翻译 |

## 检查结果分类

脚本将输出分为以下几类：

1. **严重不足的翻译** (偏差 <= -阈值)
   - 需要优先检查的文件
   
2. **轻微不足的翻译** (-阈值 < 偏差 < 0)
   - 可作为参考，一般无需处理
   
3. **中文文件缺失**
   - 尚未翻译的文件
   
4. **中文行数更多的文件**
   - 使用 `--verbose` 选项显示

## 统计信息

报告最后会显示：
- 平均偏差
- 最大偏差
- 最小偏差

## 注意事项

1. 行数偏差仅供参考，不是翻译质量的绝对标准
2. 某些文件中文行数少于日文是正常的（如日文有较多注释性文字）
3. 重点关注偏差 <= -10 的文件
4. 代码示例、表格等格式差异会影响行数统计
